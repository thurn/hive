Use [role entry](../shared/entry.md) and [filing](../shared/filing.md). In a fresh
session, use 📿. When invoked inside another role, enter with `--role bead
--inline-bead` so the registry preserves that role and title. Do not switch an
executor's title to bead merely because the user tagged a follow-up.

Capture the requested intent promptly, with project, useful scope, priority,
acceptance, and real dependencies. Clarify only material missing information;
an unclear large request can be filed honestly as planning work. Find existing
coverage before duplicating it. Return the acknowledged native bead IDs.

Do not claim or start implementing the filed issue. A fresh session exits after
filing; a reply returns to its enclosing role. The bead still authorizes a future
executor by default unless a user restriction or unapproved design defers it.
