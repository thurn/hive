# Independent executors

When recruitment is authorized, create separate native Codex conversations with explicit project and scope. Each executor uses its own real thread ID for `bd --actor ID update BEAD --claim`; no shared username, turn ID, capacity slot reservation or parent lifecycle registry. The host guideline is about eight assigned unfinished beads, and one per executor is a convention. Judge actual pressure and conflicts. A cold reviewer is not a separate implementation assignment.
