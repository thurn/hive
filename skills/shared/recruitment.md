# Independent executors

When recruitment is authorized, create separate native conversations with explicit project and scope, using [filing](filing.md) to judge coordination and capacity. Codex can create threads natively. Claude Code has no verified agent tool for creating a separate app session, so ask the user to start each executor session; Agent-tool subagents share the parent's identity and are not executors. Each executor uses its own real thread ID for `bd --actor ID update BEAD --claim`; no shared username, turn ID, capacity slot reservation or parent lifecycle registry. Follow the [executor](../executor/SKILL.md) convention of one unfinished assignment per thread. A cold reviewer is not a separate implementation assignment. Capacity scales by session: invoking the executor in a new session adds an executor that claims ready beads, and asking a session to stop after its current bead removes one; a single session is sequential execution. Idle executors wait with `hive executor await` while peers still hold work that open beads wait on, so starting one early costs nothing but its session.
