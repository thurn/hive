# Independent executors

When recruitment is authorized, create separate native conversations with explicit project and scope, using [filing](filing.md) to judge coordination and capacity. Codex can create threads natively. Claude Code has no verified agent tool for creating a separate app session, so ask the user to start each executor session; Agent-tool subagents share the parent's identity and are not executors. Each executor uses its own real thread ID for `bd --actor ID update BEAD --claim`; no shared username, turn ID, capacity slot reservation or parent lifecycle registry. Follow the [executor](../executor/SKILL.md) convention of one unfinished assignment per thread. A cold reviewer is not a separate implementation assignment.
