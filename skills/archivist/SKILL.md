---
name: archivist
description: Manual conservative cleanup of bead-linked Codex or Claude Code conversations.
---

Use [entry](../shared/entry.md). For authorized cleanup, get candidates from `hive telemetry links --json`, run as `bin/hive` in the configured `repository` because `hive` may not be on PATH (it needs `python3.12` or `HIVE_PYTHON`). Links carry relation `creator` or `executor` for every bead regardless of status, but no status; read status with native `bd show`. Deduplicate IDs. Skip a thread that is `executor` of any bead not closed. A `creator`-only link does not block archiving. User-supplied threads may be added explicitly; do not search titles or the full conversation index for default membership.

For each candidate, require native evidence of no active or queued turn and at least 15 minutes without input, output or tool activity. Inspect descendants affected by native archive; unknown effects or activity mean skip. Recheck immediately before archive. Recheck afterward and promptly unarchive affected threads/descendants if activity raced it. Never stop a turn to make it eligible, and never change bead ownership. A closed bead alone proves nothing. Report capability limits when the native tools cannot establish safety. Codex thread IDs are UUIDv7 and Claude session IDs UUIDv4; each host skips the other's threads, leaving them for an archivist run on that host.

In the Claude desktop app, use `get_session`, `archive_session` and `unarchive_session`. They address sessions by app ID (`local_...`), not the `CLAUDE_CODE_SESSION_ID` stored on beads. Archive only when the user or a native record establishes that mapping; otherwise skip. The app's session record, `~/Library/Application Support/Claude/claude-code-sessions/*/*/local_*.json`, holds `sessionId` and the bead-side `cliSessionId`; it is undocumented app state, so skip when it is absent or lacks either field. `isRunning` and `lastActivityAt` are the activity evidence; queued input is not exposed, so skip when unsure. Archiving also archives finished side sessions sharing the worktree. Find descendants with `get_session`, which reports `parentSessionId`, on every unarchived session from `list_sessions`; its default `limit` is 20, so raise it until the list is complete, or treat descendants as unknown. The app may refuse pinned or on-screen sessions; report the refusal rather than retrying. Each archive asks for approval except in auto mode, which may approve silently, and bypass permissions mode. Plain Claude Code CLI sessions have no archive tool.
